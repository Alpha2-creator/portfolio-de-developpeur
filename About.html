À propos de moi

Qui suis-je ?

Je suis un apprenant passionné par le développement web, la programmation et les nouvelles technologies.

Je développe progressivement mes compétences à travers des projets pratiques afin de mieux comprendre la création de sites web et de solutions numériques.

Mon objectif est de devenir un développeur capable de concevoir des applications web modernes, utiles et adaptées aux besoins des utilisateurs.

Mon parcours

J'ai commencé mon apprentissage du développement web en travaillant sur les bases du HTML, du CSS et de JavaScript.

En parallèle, je développe mes connaissances en Python et en analyse de données avec des outils comme Pandas, Matplotlib et Seaborn.

Je pratique également Git et GitHub afin d'apprendre à gérer mes projets et à travailler avec les bonnes pratiques du développement logiciel.

Mes objectifs

  • Maîtriser le développement web
  • Créer des projets web professionnels
  • Développer mes compétences en Python et en Data
  • Apprendre les bonnes pratiques du développement
  • Construire progressivement un portfolio professionnel

Technologies que j'apprends

  • HTML5
  • CSS3
  • JavaScript
  • Python
  • Pandas
  • Matplotlib
  • Seaborn
  • Git
  • GitHub

Ma motivation

Je crois que la meilleure façon d'apprendre le développement est de pratiquer régulièrement et de construire des projets concrets.

Chaque projet me permet d'apprendre de nouvelles choses, de résoudre des problèmes et d'améliorer progressivement mes compétences.
